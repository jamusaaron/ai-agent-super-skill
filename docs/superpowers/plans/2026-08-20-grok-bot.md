# Grok Bot Implementation Plan

> **For agentic workers:** Execute inline in this session (cloud/background agent; no extra subagents). Use TDD: failing test → implement → passing test. Commit frequently.

**Goal:** Ship a FastAPI Grok chat bot with a distinctive web UI, session history, streaming, tests, and docs.

**Architecture:** FastAPI serves JSON/SSE APIs and a static frontend. An OpenAI-compatible client talks to `https://api.x.ai/v1`. Sessions live in memory.

**Tech Stack:** Python 3.11+, FastAPI, Uvicorn, OpenAI SDK, Pydantic Settings, pytest, vanilla HTML/CSS/JS.

## Global Constraints

- API key only from `XAI_API_KEY`; never commit secrets.
- Default model `grok-4.6` via `GROK_MODEL`.
- Base URL `https://api.x.ai/v1` via `XAI_BASE_URL`.
- Mock xAI in all tests.
- Keep existing root `SKILL.md`.
- App lives under `grok-bot/`.
